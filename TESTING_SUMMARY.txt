3. TESTING PATTERNS USED
═══════════════════════════════════════════════════════════════════════════════

Pattern A: Model Tests
─────────────────────
Inherits from: ActiveSupport::TestCase
Test Method: test "description" { ... }
Assertions: assert_equal, assert_nil, assert_empty, etc.
Example:
  test "downcases and strips email_address" do
    user = User.new(email_address: " TEST@EXAMPLE.COM ")
    assert_equal("test@example.com", user.email_address)
  end

Pattern B: Controller/Integration Tests
──────────────────────────────────────
Inherits from: ActionDispatch::IntegrationTest
HTTP Methods: get, post, patch, put, delete
Assertions: assert_response, assert_redirected_to, assert_select
Auth Helper: sign_in_as(user) from SessionTestHelper
Example:
  test "create with valid credentials" do
    post session_path, params: { email_address: @user.email_address, password: "password" }
    assert_redirected_to root_path
  end

Pattern C: Turbo Stream Tests
──────────────────────────────
Inherits from: ActionDispatch::IntegrationTest
Headers: { "Accept" => Mime[:turbo_stream].to_s }
Assertions: assert_turbo_replace, assert_match for stream content
Example:
  test "habits create returns turbo replacement" do
    post habits_path, params: { habit: { name: "Read" } }, headers: turbo_headers
    assert_response :success
    assert_turbo_replace("habits_content")
  end

7. KEY ASSERTIONS
═══════════════════════════════════════════════════════════════════════════════

Equality & Truthiness:
  assert(expression)
  assert_equal(expected, actual)
  assert_nil(value)
  assert_empty(array)
  assert_includes(array, value)
  assert_not_nil(value)

Response & Redirect:
  assert_response :success              # 200
  assert_response :created              # 201
  assert_response :unprocessable_entity # 422
  assert_response :redirect
  assert_redirected_to path_or_controller

HTML & Content:
  assert_match(/pattern/, @response.body)
  assert_select "css_selector"
  assert_select "div#id"
  assert_select "div", text: "content"

Database:
  assert_difference('Model.count', 1) { action }
  assert_no_difference('Model.count') { action }

Time:
  assert_operator(date, :>, Date.current)
  assert_in_delta(expected, actual, 0.01)

Exceptions:
  assert_raises(ExceptionClass) { code_block }
